# Hack The Box Walkthroughs & Notes

This directory contains my detailed write-ups, methodology, enumeration logs, and exploitation steps for machines and challenges completed on [Hack The Box](https://www.hackthebox.com/).

---

## Machine Methodology

Every HTB write-up follows a standard penetration testing methodology:
1. **Reconnaissance & Enumeration**: Nmap scans, service identification, web directory fuzzing.
2. **Initial Access**: Vulnerability exploitation, payload execution, initial shell access.
3. **Privilege Escalation**: System analysis, misconfigurations, root/administrator shell capture.
4. **Key Takeaways**: Mitigation steps and core learning points.
